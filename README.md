# WatchApp

WatchApp is an implemented, pre-hardware-validation personal companion system for a Galaxy Watch6 Classic and iPhone. It pairs a custom Wear OS sensor application with a minimal OLED SwiftUI dashboard, local-first encrypted Bluetooth synchronization, Apple Health export, bounded raw recordings, and an experimental notification laboratory.

The product specification is in [PLANNING.md](./PLANNING.md), and current validation gates are tracked in [docs/IMPLEMENTATION_STATUS.md](./docs/IMPLEMENTATION_STATUS.md).

Important boundary: WatchApp does not replace Galaxy Wearable, cannot perform the official Watch6-to-iPhone setup, and does not promise universal notification replies.
